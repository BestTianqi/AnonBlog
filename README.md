# Anon's Blog

[https://besttianqi.github.io/AnonBlog](https://besttianqi.github.io/AnonBlog)

はじめまして、千早愛音と申します。MyGO!!!!! ギター担当。

A personal blog built with Next.js, featuring Markdown posts, code highlighting, dark mode, full-text search, and a music player with MyGO!!!!! songs.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## Build & Deploy

Static export to GitHub Pages via GitHub Actions.

```bash
npm run build
```

Output in `out/`.
